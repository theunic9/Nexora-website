# Nexora — Digital Intelligence

Website institucional experimental, desenvolvido como projeto front-end premium com foco em design, responsividade, profundidade visual e interação.

## Destaques

- Tela de entrada imersiva com galáxia 3D em WebGL
- Three.js via CDN
- Layout responsivo
- Efeitos de profundidade e interação com ponteiro
- Microinterações e animações
- Menu mobile
- Seções institucionais, serviços, diferenciais, processo, depoimentos, FAQ e contato
- Acessibilidade básica
- `prefers-reduced-motion`
- SEO básico

## Executar localmente

Abra `index.html` em um navegador moderno. Para desenvolvimento, use um servidor local, como o Live Server do VS Code.

## GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todo o conteúdo deste diretório.
3. Vá em **Settings → Pages**.
4. Escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)`.
6. Salve.

## Dependência externa

A galáxia 3D utiliza Three.js via CDN e depende de conexão com a internet.
